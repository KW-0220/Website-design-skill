# DESIGN.md library index

From VoltAgent/awesome-design-md (MIT). Each file is `design-md/<slug>.md`: YAML tokens (colors, typography, spacing, radii, components) plus prose rules. They are *inspired-by* analyses of public sites: use one as a design language, never to copy a brand's logo, name, imagery or copy.
